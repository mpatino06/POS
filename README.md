# 🛒 Gestor de Ventas

Este proyecto es un **Gestor de Ventas** desarrollado en **.NET 9** utilizando el enfoque de **Minimal API**.  
La solución sigue principios de **Clean Code** y aplica patrones de diseño como **Repository** y **Unit of Work** para garantizar mantenibilidad y escalabilidad.

## 🚀 Tecnologías utilizadas
- **.NET 9** con Minimal API
- **Clean Code** para buenas prácticas de desarrollo
- **Mapper** para transformación de objetos
- **FluentValidation** para validaciones robustas
- **Patrón Repository** para abstracción de acceso a datos
- **Unit of Work** para manejo de transacciones
- **Entity Framework Core** como ORM
- **SQL Server** como base de datos principal

## 📌 Características principales
- Gestión de productos, clientes y ventas
- Validaciones centralizadas con **FluentValidation**
- Separación de responsabilidades con **Repository** y **Unit of Work**
- Persistencia en **SQL Server** con **EF Core**
- Código limpio y mantenible siguiendo principios de **Clean Code**
